## 확인한 구조

- 프론트: Vue 3 / TypeScript / Vite / Pinia / Tailwind CSS. `src/api`, `composables`, `views`, `components`로 분리.
- 백엔드: Python 3.12 / Django 5.1 / DRF. `apps/users`, `performances`, `recommendations`, `community`, `logs`.
- API 진입점: `BE/urls.py`, `/api/v1/`.
- 프론트 `netlify.toml`은 `/api/*`를 Elastic Beanstalk HTTP 주소로 프록시한다.
- 운영 Compose: Gunicorn, Celery Worker, Celery Beat. README에 RDS PostgreSQL / ElastiCache Valkey / S3 구성 명시.
- 로컬 Compose: PostgreSQL 16, Redis 7, web/worker/beat.
- 추천: 사용자 행동 및 요청 조건 → 규칙/특성 가중치 기반 후보 선정 → LLM 순위·이유 생성 → 후보 검증 → 세션 저장. 실패 시 규칙 기반 fallback.
- `apps/recommendations/openai_client.py`는 OpenAI 직접 호출과 SSAFY GMS 경유 호출을 지원한다. 코드 기본 모델은 각각 gpt-4o-mini / gpt-4.1이며 운영 환경값은 미확인.
- 추천 피드백과 학습 데이터 추출 코드가 존재한다. 실제 데이터 규모·품질·사용 권한은 미확인.
